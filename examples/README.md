# Editorial examples and regression references

The Brain's reusable insight is **approved exemplars with provenance**, not copying its private Yann drafts or adding a new model role.

- Only an explicit operator decision makes a copy sample **Golden**. A Critic PASS, draft, historical publication or a copied example is not an automatic approval.
- An example should be matched by **brand, channel, format and rhetorical purpose**. Two or three short, relevant examples are better than dumping a corpus.
- Store the exact sample plus the operator's explanation of its useful choices (position, reader problem, cadence, CTA). Mark non-generalizable traits and prohibitions on direct imitation.
- Include operator-rejected drafts as **negative tests**, clearly separate from approved samples.
- Never promote one rejection into a universal rule without checking contrasting acceptable examples.
- All actual client examples stay outside public git by default. Prefer local `runs/<job>/inputs/calibration.md` or operator-controlled sources, with redaction where needed.

The public `tests/critic/fixtures/` folder may contain synthetic contrasts. Synthetic rubric tests do not prove real editorial effectiveness.
